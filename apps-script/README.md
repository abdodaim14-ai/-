# تفعيل نظام طلبات التلاوات وتتبعها

رابط Web App الذي رُبط به الموقع حاليًا:
`https://script.google.com/macros/s/AKfycbyAv0B18pikXLjPV3eV0PMOYXhjxQ7mAyMu8vwjq9exqjIx5GJJu5mCusWZxTv6Bl-7gA/exec`

> هذا رابط تطبيق Google Apps Script المنشور (Web App)، وليس رابط فتح جدول Google Sheets نفسه. يجب أن يكون مشروع Apps Script مربوطًا بجدول التسجيلات الصحيح.

## خطوة التفعيل المطلوبة في Google Apps Script

1. افتح مشروع Apps Script المرتبط بجدول التسجيلات الذي يستقبل البيانات.
2. خذ نسخة احتياطية من الكود القديم قبل تغييره.
3. افتح `apps-script/Code.gs` في GitHub وانسخ الكود كاملًا إلى ملف `Code.gs` في مشروع Apps Script.
4. تأكد أن المشروع مربوط بنفس جدول البيانات القديم، وأن الأعمدة الأصلية A:J لم تتغير.
5. من **Deploy → Manage deployments** افتح نشر Web App الحالي واضغط تعديل (القلم)، ثم اختر **New version** واضغط **Deploy**. بهذه الطريقة يظل رابط النشر نفسه.
6. إعداد التشغيل: **Execute as: Me**، وإتاحة الوصول: **Anyone** أو **Anyone, even anonymous** حسب الخيارات الظاهرة؛ لأن صفحة التتبع عامة. لا تستخدم رابط `/dev`.
7. وافق على صلاحيات Google Drive وGoogle Sheets عند ظهورها.
8. افتح رابط Web App نفسه في نافذة متصفح عادية. يجب أن يعرض JSON فيه `totalCount` و`latestReaders`، ثم اختبر البحث برقم طلب موجود.

## دورة الطلب

- التسجيل الجديد يضيف البيانات الأصلية إلى A:J ورقم الطلب إلى K، والحالة إلى L.
- لوحة الإدارة `admin.html` تعرض الطلبات، والصورة والتسجيل، وتسمح بالقبول أو الرفض.
- عند الرفض يجب كتابة سبب واضح؛ يظهر السبب لصاحب الطلب في `track.html`.
- يستطيع صاحب الطلب إعادة التقديم من صفحة التتبع باستخدام رقم الطلب ورقم الهاتف المسجل، واستبدال الصورة أو التسجيل أو الاثنين.
- بعد إعادة التقديم ترجع الحالة تلقائيًا إلى «إعادة التقديم - قيد المراجعة».

## أعمدة التتبع

- A:J: البيانات الأصلية كما هي.
- K: رقم الطلب.
- L: حالة الطلب.
- M: سبب الرفض أو الملاحظة الموجهة للمتقدم.
- N: آخر تحديث.
- O: عدد مرات إعادة التقديم.

## لوحة الإدارة والأمان

قائمة الطلبات في لوحة الإدارة لا تُعرض إلا بعد التحقق من جلسة Supabase وصلاحية `admin_check_access`. لا تضع مفتاحًا سريًا أو Service Role Key في ملفات الموقع. مفتاح Supabase المنشور المستخدم هنا هو المفتاح العام فقط.

## الخطوط والهوية

رفع ملف الخط من لوحة الإدارة يحفظ بيانات الخط في إعدادات المظهر، ويقرأه ملف `site-theme.js` لتطبيقه على الصفحات الأساسية. الأنواع المدعومة: TTF وOTF وWOFF وWOFF2، بحد أقصى 450 كيلوبايت.

**مهم:** تعديل GitHub لا يحدّث Apps Script تلقائيًا. لا بد من نسخ الكود ونشر إصدار جديد كما في الخطوات أعلاه. لا تحذف جدول البيانات أو صفوف التسجيلات القديمة.
