# تفعيل نظام تتبع طلبات التلاوة

تمت إضافة واجهة التتبع إلى الموقع، لكن استقبال رقم الطلب وحفظه يحتاج تحديث Google Apps Script المرتبط بنموذج التسجيل.

## خطوات التفعيل مرة واحدة

1. افتح مشروع Google Apps Script المرتبط برابط التسجيل الحالي.
2. احتفظ بنسخة من الكود القديم في ملف نصي احتياطي.
3. افتح الملف `apps-script/Code.gs` في هذا المستودع وانسخ محتواه بالكامل إلى ملف `Code.gs` في مشروع Apps Script، مع استبدال الكود القديم.
4. تأكد أن المشروع مربوط بنفس Google Sheet الذي يستقبل التسجيلات حاليًا، وأن ترتيب الأعمدة الأصلية A:J لم يتغير.
5. من Apps Script اختر **Deploy → Manage deployments** ثم افتح نشر Web app الحالي واضغط **Edit**، واختر **New version** ثم **Deploy**. استخدم نفس صلاحيات الوصول التي كان عليها النشر السابق.
6. اختبر إرسال طلب تجريبي، وتأكد من ظهور رقم الطلب في العمود K.
7. لتغيير حالة أي طلب، عدّل العمود L في نفس الصف. ويمكن وضع ملاحظة داخلية في العمود M؛ هذه الملاحظات لا تظهر في صفحة التتبع العامة.

## الأعمدة

- A:J: البيانات الأصلية كما هي.
- K: رقم الطلب.
- L: حالة الطلب، وتبدأ بـ «تم استلام الطلب».
- M: ملاحظات الإدارة الداخلية.

## الصفحات

- الصفحة الرئيسية: نموذج التسجيل وبطاقة رقم الطلب وبحث التتبع.
- `track.html`: صفحة مستقلة متوافقة مع الموبايل والكمبيوتر.

**مهم:** تحديث ملفات GitHub وحده لا يحدّث مشروع Google Apps Script. لازم تنفيذ خطوات النشر أعلاه حتى يبدأ السيرفر في حفظ أرقام الطلبات والرد على عمليات البحث.
